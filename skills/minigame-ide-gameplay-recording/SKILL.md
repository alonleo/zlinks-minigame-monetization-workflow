# IDE 游戏过程录屏

本 skill 只录制目标平台 IDE 当前打开的指定构建产物。录像是 IDE 模拟器证据，不替代真机、真实广告、平台登录、兼容性或性能验收。

开始执行前完整读取总工作流的 [Git 检查点、阶段标签与推送协议](../../references/git-checkpoints.md)。所有适用平台录屏通过后，把脱敏回执和证据索引写入工程台账，创建 `recording` 阶段汇总提交和 annotated tag，并推送、核验远程；Git 门禁失败时阶段不得报告 `completed`。

如需修改或新增录屏辅助脚本，只能使用 Python。

## 开始条件

取得目标平台、构建绝对路径及标识、IDE 及版本、画面范围、分辨率、帧率、声音要求、可重复操作步骤、关键验收点和敏感区域。平台或构建不明确时不得开始录制。

## 执行

完整读取 [录屏执行协议](references/execution-protocol.md)，然后：

1. 冻结录制清单和逐步操作脚本；
2. 使用 `scripts/ide_recording.py` 预检 FFmpeg、FFprobe 和唯一目标窗口；
3. 按清单复位账号、缓存、存档、网络和关卡前置状态；
4. 启动录制并保存会话文件后，才执行操作步骤；
5. 记录每步时间、结果、重试和异常；
6. 停止录制，核验 MP4、日志、时长、关键画面、媒体信息和 SHA-256；
7. 各平台分别交付，不互相替代。

不得为了画面顺畅跳过清单要求的真实行为。窗口匹配不唯一、构建无法确认、敏感信息泄露、关键步骤不可见或回执缺失时，不得标记通过。

## 阶段回执

输出 `completed | partial | blocked | failed`，并包含录制清单、平台、构建路径及标识、IDE 版本、逐步执行记录、MP4、会话与媒体回执、文件哈希、阶段汇总 commit、annotated tag、远程推送核验，以及声音、真机、广告和网络环境等未覆盖项。
